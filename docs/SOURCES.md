# Innehålls- och bildkällor

- Publik livesida och de fem canonical-sidorna på https://agroveterinaria.com.py/ granskades 5 oktober 2026. Sparad HTML/JS, robots och sitemap i `reference/`; HTTP-status och metadata i `evidence/live-crawl.json`.
- Kategorierna är återanvända från live: alimentos balanceados, medicamentos veterinarios, vacunas para ganado, antiparasitarios, insumos ganaderos. Detta bevisar endast att kategorierna omnämndes; det verifierar inte försäljning, produktgodkännande, tillgång eller sortiment.
- `STEP-0-RECON.md` beskriver en plan och öppna frågor. Föreslagna affärsfakta, sökvolymer, habiliteringar, leveransområden och kontaktuppgifter har inte införts som fakta. Alternativgrenens KWP-underlag ändras inte och inga ranking-/volympåståenden görs.
- https://senacsa.gov.py/ verifierades som aktuell officiell webbplats via webbläsande den 5 oktober 2026; www-versionen redirectar dit. Används endast som länk till officiell information. Ingen aktuell vaccinperiod, reglering, produktspecifikation eller habilitering påstås i sajten.
- Två AI-illustrationer beställdes via Higgsfield med GPT Image 2.5 Sunburst Medium. Jobb/kostnader finns i `media-ledger.json`. Ingen förpackning, etikett, personal, kund, leveransverksamhet eller registreringshandling genererades.

Sajttexten ger inga diagnoser, doser, terapier, läkemedelsinstruktioner eller produktgodkännanden. Den skiljer kommersiell produktreferens från veterinärbedömning och hänvisar individuella frågor till veterinär. Inga tunna ortssidor eller fabricerade produktposter skapades.
